**Предметна область:** Обмінний пункт (валютні операції)

## Призначення

Програма читає набір записів про валютні операції з файлу `data/input.csv`, перевіряє їх, обчислює чотири показники та формує звіт у консоль і текстовий файл.

## Формат вхідних даних

Файл `data/input.csv` має кодування UTF-8. Кожен рядок містить чотири поля, розділені крапкою з комою (`;`):

1. `currency` – код валюти (текст, обов'язкове)
2. `amount` – сума в іноземній валюті (додатне число)
3. `rate` – курс обміну (додатне число)
4. `buy` – тип операції: `true` – купівля, `false` – продаж (логічне значення)

## Збірка та запуск

Для збірки використовується Maven Wrapper. Команди:

- Windows: `mvnw.cmd clean verify`
- Unix/macOS: `./mvnw clean verify`

Для створення виконуваного JAR:

- Windows: `mvnw.cmd package`
- Unix/macOS: `./mvnw package`
