## Призначення

Програма читає набір записів про валютні операції з файлу `data/input.csv`, перевіряє їх, обчислює чотири задані показники та формує звіт у консоль і текстовий файл.

**Чотири показники, які обчислюються згідно з варіантом:**
1. Кількість коректних записів (`validCount`) – тип `int`;
2. Сумарний еквівалент у гривні (`totalEquivalent`) – тип `double` (сума `amount * rate`);
3. Середній курс (`averageRate`) – тип `double` (середнє арифметичне `rate`);
4. Кількість операцій купівлі (`buyCount`) – тип `int` (кількість записів, де `buy == true`).

## Формат вхідних даних

Файл `data/input.csv` має кодування UTF-8. Кожен рядок містить чотири поля, розділені крапкою з комою (`;`):

1. `currency` – код валюти (тип String, не порожній рядок);
2. `amount` – сума в іноземній валюті (тип double, додатне число);
3. `rate` – курс обміну (тип double, додатне число);
4. `buy` – операція купівлі: `true` – купівля, `false` – продаж (тип boolean, значення `true` або `false`).

**Приклад коректного запису:** USD;100.00;41.50;true

## Збірка та запуск

Для збірки використовується Maven Wrapper. Команди:

- Windows: `mvnw.cmd clean verify`
- Unix/macOS: `./mvnw clean verify`

Для створення виконуваного JAR:

- Windows: `mvnw.cmd clean package`
- Unix/macOS: `./mvnw clean package`

JAR з'явиться у `target/lab01-1.0.0.jar`.

**Запуск програми:**

```
java -jar target/lab01-1.0.0.jar
```
## Аргументи командного рядка

| Аргумент       | Призначення                          |
|----------------|--------------------------------------|
|--help          | Показати довідку                     |
|--version       | Показати версію програми             |
|--input <файл>  | Вказати шлях до вхідного CSV-файлу   |
|--output <файл> | Вказати шлях до вихідного файлу звіту|

**Приклад використання:**
```
java -jar target/lab01-1.0.0.jar --input mydata.csv --output myreport.txt
```
